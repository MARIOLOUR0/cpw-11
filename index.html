Bem-vindo ao clube

O Clube TechLab é um espaço para aprender, experimentar tecnologia e partilhar projetos.

Conhece a mostra do clube

Oficinas do clube

Criação de páginas web

Nesta oficina, aprendemos a utilizar HTML para criar páginas web e apresentar os nossos projetos.

Robótica

Nesta atividade, exploramos a robótica e aprendemos a construir e testar pequenos projetos.

Programação de jogos

Aprendemos conceitos de programação e desenvolvemos ideias para criar jogos simples.

Próxima sessão

Construir uma página para o clube

Na próxima sessão, vamos planear e criar uma página para apresentar os projetos do clube. Primeiro organizamos as ideias; depois escrevemos o HTML e revemos o resultado em conjunto.

Material necessário

  • Computador com navegador
  • Caderno para esboços
  • Lápis e borracha
  • Ficheiros dos projetos anteriores
