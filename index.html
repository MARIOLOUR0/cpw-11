Clube TechLab

O Clube TechLab é um espaço para descobrir tecnologia, experimentar novas ideias e criar projetos em conjunto.

Atenção: é importante guardar o trabalho antes de fechar o VS Code.

Atividades

No clube, podemos aprender diferentes áreas da tecnologia e trabalhar em projetos criativos.

Oficina de páginas web

Vamos aprender a criar páginas web e apresentar os nossos projetos. Queremos criar ideias novas em conjunto.

  • Criação de páginas web

Como participar

Para participar nas atividades do clube, segue estes passos:

  1. Escolher uma atividade.
  2. Participar nas experiências do clube.
  3. Criar e partilhar um projeto.
